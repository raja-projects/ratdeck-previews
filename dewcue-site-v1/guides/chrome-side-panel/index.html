How to use DewCue’s Chrome side panel while you work

Keep the same reminder list beside your page, review Today and Overdue, and choose a useful next action without making a separate list.

DewCue guides·3 min read·Documentation reviewed 18 October 2026

The useful answer

Open DewCue in Chrome’s side panel when you want your reminder list beside the page you are using. The panel shows the same reminders with more room. Use it to review what is due and keep the next task in sight while you browse.

Use one list in a roomier view

The side panel is another place to see your existing reminders. You do not need to copy tasks into a separate list for this view. That makes it useful when the page in front of you is part of the task you need to complete.

For example, you might keep a document open while reviewing the reminder to request feedback. The panel supplies the task context; you still choose what to do on the page.

Review the day before adding more work

Start with the reminders you already have. Today shows the work due now, Upcoming helps you see what is ahead, and Overdue brings unfinished reminders back to your attention.

Treat an overdue reminder as a decision to make. If the task is finished, mark it done. If you need more time, snooze it or use remind again so its status reflects what you intend to do.

  1. Open the DewCue side panel beside the page you are using.
  2. Review Today and check Overdue for unfinished work.
  3. Choose one reminder that you can act on in the current session.
  4. Update the task’s status when you finish or decide to return later.

Keep useful context close to the task

For a page-based task, a deliberate capture can keep its title, address, and selected text. For an email follow-up, DewCue can keep the visible subject, sender name, and message link after you start capture.

These are ways to make the reminder useful when you return. The panel does not create a second copy of the reminder list or establish that locally saved context has synced to another computer.

Check your alert separately

The side panel helps you review the list while it is in view. Your reminder alert is a separate choice: an on-page card or a system notification. Test that choice with Chrome open and the computer awake before depending on it.

If you cannot find DewCue’s panel in your installed version, contact support with the extension version and a description of what you see.

A few related questions

Can I see my reminders beside the page I am working on?
Yes. DewCue’s Chrome side panel puts the same reminder list beside your current page with more room to view it. You do not need to create a separate set of reminders for the panel. Review Today, Upcoming, and Overdue to choose your next action.
Use the side panel while browsing
How are my reminders organized?
DewCue separates reminders into Today, Upcoming, and Overdue. Today helps you see what needs attention now, Upcoming shows what is ahead, and Overdue helps you revisit unfinished reminders. The side panel shows the same reminder list.
See a simple work routine
What can I do when a reminder appears?
Mark it done when the task is finished, snooze it when you need more time, or use remind again when it still needs your attention. Choose the action that reflects the task's actual status to keep your list useful.
Build a simple reminder routine
Where will my reminders appear?
You can choose on-page reminder cards or system notifications. On-page cards need permission when you enable that option. For system notifications, also check whether your operating system allows Chrome to display alerts.

    <h1>Privacy Policy</h1>
    <p class="updated">Last updated 17 October 2026. This page describes what the Dewcue Chrome extension, version 1.0.0, actually does with information.</p>

    <h2>What stays on your computer</h2>
    <p>Dewcue is local-first. It does not have an account system for your reminders.</p>
    <p>Reminders, quiet hours, and the notification choice are saved with <code>chrome.storage.sync</code>, so they are there on computers signed into the same Chrome profile.</p>
    <p>Buckets, update logs, the timer, wellness nudges, milestones, birthdays, themes, follow-up preferences, and the completed history stay in local storage on this computer. A backup file you download is yours. Dewcue does not upload that file.</p>
    <p>Rating notes you type stay on this computer. There is no feedback server. A 14-day Premium trial, if you start one, is recorded on this computer and does not need a card.</p>

    <h2>Pages</h2>
    <p>Installing Dewcue does not ask for access to your sites. Dewcue does not read or store the content of pages you visit, and it does not collect browsing history.</p>
    <p>If you choose on-page reminder cards, Chrome asks for permission to run on sites. Dewcue uses that only to draw its own small card. The card does not read or store the page underneath it.</p>
    <p>If you use the toolbar or the right-click menu, Dewcue saves the page title, the address, and any text you selected, because you asked it to. That copy stays on your computer. It is not sent to a Dewcue server.</p>

    <h2>Email</h2>
    <p>Dewcue does not ask for an email account. It does not use Google, Microsoft, or Yahoo sign-in, and it does not read your mailbox.</p>
    <p>On Gmail, Outlook on the web, and Yahoo Mail, if you allow the reminder on that site, Dewcue can read the subject, the sender name, and the message link that are already on screen. It uses those only to offer a follow-up or save a reminder. It does not read the message body or the inbox list. Nothing about the email is sent to a Dewcue server.</p>
    <p>About once a day Dewcue may download a data-only file of selectors from dewcue.com so on-screen mail layouts can be corrected without an update. That request contains no account, no page, and no email. The file is not code.</p>

    <h2>Premium and payments</h2>
    <p>Premium is billed by Razorpay, the payment processor. Checkout opens in a browser tab. Card numbers and UPI ids are handled by Razorpay, under Razorpay’s own privacy policy, not by Dewcue.</p>
    <p>The licence server stores only the email address you type, the licence status, and an installation id for the computer you activate. It does not store page content, email subjects, or reminders. The extension re-checks the licence about once a day. If that check cannot get online, Premium keeps working for 7 days from the last successful check.</p>
    <p>You can remove Premium from a computer inside Dewcue. That unbinds the computer. It does not delete your reminders.</p>

    <h2>What Dewcue does not do</h2>
    <ul>
      <li>It does not sell data.</li>
      <li>It does not use analytics or advertising.</li>
      <li>It does not collect health records or location.</li>
      <li>It does not use your data for credit or lending decisions.</li>
    </ul>

    <h2>How long it is kept</h2>
    <p>Data in Chrome stays until you delete it, export it and remove it, or uninstall the extension. Uninstalling removes the local copy. Chrome sync may still hold reminders on your Google account until Chrome removes them. Licence records on the server are kept so a paid licence can be restored. To ask about a licence record, write to <a href="mailto:hello@dewcue.com">hello@dewcue.com</a>.</p>
